# AdventureCraft Legacy 0.7.0

This update brings native Vulkan rendering, optional ray-traced lighting, and improvements to map editing, scripting, and saving.

## Compatibility

- Require a Vulkan-capable graphics driver and replace the external `AC-LWJGL3-Injector` with compatibility support bundled with the mod.
- Use AdventureCraft's built-in shaders. Legacy OpenGL/Macula shader packs are detected but cannot run their custom shader programs.
- Require JDK 27 for development and game launches; Gradle selects or provisions the matching toolchain.
- Remove unsupported legacy Advanced OpenGL, anti-aliasing, and anisotropic-filtering controls while retaining their saved configuration values.
- Offer NVIDIA SHARC indirect lighting through a separately licensed optional SDK. Ordinary rendering and hardware ray tracing work without it.
- Add optional native DLSS and NRD integrations with separate license acceptance, verified SDK downloads outside the repository, remembered development setup, and cached offline builds.

## Rendering

- Add map-local materials, PBR companion textures, animated material channels, and live material reloads.
- Add optional hardware ray tracing, off by default, with capability checks and a raster fallback. Trace terrain shadows, nearby emissive lights, indirect lighting, and translucent-terrain reflections while preserving custom geometry, cutouts, map textures, and biome colors.
- Preserve original display colors with Ray Tracing off. Apply HDR exposure, bloom, and tone mapping to ray-traced rendering, with automatic exposure that excludes hands and HUD.
- Add independent Temporal AA and Render Scale options. Render the world at Native, 85%, 75%, 67%, or 50% resolution while keeping hands, screen effects, HUD, and menus at native resolution.
- Add a dedicated **Video Settings → Ray Tracing** page for lighting, reconstruction, upscaling, and frame generation. Show supported saved selections, capability reasons, and active status while retaining unavailable preferences.
- Add NVIDIA DLSS Ray Reconstruction, separate NRD diffuse/specular lighting denoisers, and DLSS Super Resolution or AMD FSR temporal upscaling. Preserve classic display colors, native hands and HUD, and built-in rendering when a feature is unavailable or a native dispatch fails.
- Add DLSS and AMD FSR Frame Generation on supported devices, with history resets and ordered presentation. Generated frames do not increase the simulation rate.
- Stabilize terrain, sky, foliage contours, and noisy lighting with validated temporal history. Reconstruct rejected regions at a stable pixel center, reject changed texture footprints locally, and keep dynamic content responsive.
- Add Off/Fast/Fancy parallax mapping for opaque ray-traced terrain using normal-atlas height data. Relief remains a surface effect without changing block geometry or shadows.
- Improve many-light stability, bonfire falloff, foliage shading, sealed-cave darkness, and lighting continuity when nearby chunks rebuild. Invisible Clip Blocks also block traced light.
- Add a shared day/night atmosphere, volumetric clouds, atmospheric haze, underwater absorption, and gradual rain wetness while preserving map-authored sky textures and fog boundaries.
- Add water waves, rain ripples, reflections, and refraction. Preserve authored animated water detail, transparency, and visibility of actors and particles through water.
- Preserve draw order, masked clears, retained textures, and resource lifetimes across terrain, entities, particles, scripted graphics, and interface rendering.

## Performance

- Add per-frame budgets for terrain preparation and uploads, prioritize nearby sections, and combine repeated rebuild requests. Apply memory backpressure, cancel obsolete builds, and release pending resources when leaving a world.
- Request the exact padded source columns needed by terrain builds and check asynchronous storage readiness before taking snapshots. Reserve processor capacity when sizing mesh workers.
- Build terrain from captured lighting, materials, foliage colors, tile definitions, and custom render data. Reject outdated results after intervening edits or material reloads, and keep mutable lighting tables out of worker reads.
- Cache repeated lighting calculations within each terrain build, skip air during mesh traversal, and create meshers only for used texture/layer combinations. Preserve mesh output, skylight tracking, and hidden Clip Block occluders.
- Index trigger-area membership queries and remove per-block activation allocations while preserving overlap counts, replacement order, and callbacks that change later blocks or trigger areas.
- Reduce held-torch block reads and combine renderer invalidations by section, including cleanup of previous light positions. Preserve brightness, movement cadence, and gameplay-listener notifications.
- Stop collision presence queries at the first hit while retaining custom collision shapes and complete ordered lists for movement resolution and editor collision visualization.
- Use the path query's owning world for dynamic collision-shape checks, skip consumed path nodes during smoothing, and preserve existing route and clearance-query order.
- Separate terrain scheduling, mesh generation, trigger tracking, collision queries, path smoothing, and script scheduling into dedicated components.

## Map editing and interface

- Keep editor mode, selection, reach, debug settings, and undo/redo history with their world. Improve grouped undo operations and restore the correct selection.
- Apply map-setting sliders when their input changes. Clarify that a Light Bulb controls its own emission, solid blocks form visible walls, and Clip Blocks remain invisible light barriers.
- Preserve legacy option identities and saved settings, improve render-distance migration, and default new configurations to Fancy fog.
- Restore connected locked-door textures in older maps, preserve closed segmented doors, and clear stale segments when doors become shorter.
- Improve resource cleanup for file-picker icons and other interface textures.

## Scripting

- Isolate script runtimes by world and release pending timers, sleeping scripts, and runtime state when leaving a map.
- Restore legacy entity/ray-trace array access, scripted cursor rotation resets, and saved script-block and entity scopes.
- Remove linear searches from ordinary timeout cancellation while preserving deadline/ID ordering, callback arguments, and same-tick cancellation. Allow callbacks to safely schedule new timers for a later timer run.
- Schedule sleeping scripts by wake deadline while preserving capture order among due scripts and deferring scripts that sleep again. Preserve continuation-before-timer execution and microtask ordering.
- Preserve scripted models and UI on the Vulkan renderer, and improve script statistics and music lookup.

## World resources and saving

- Fix rectangular storage-block regions crashing or restoring blocks at incorrect positions. Restore saved tile-entity settings, including free trades and their rewards.
- Preserve the distinction between playing a map and editing its source when loading resources and saving changes.
- Snapshot chunks before asynchronous saving, report save failures, and allow later saves to recover.
- Correct relocated chunk coordinates and preserve primitive NBT lists when reading, copying, or modifying saved data.

## Window, input, audio, and tooling

- Update to LWJGL 3.4.3 with bundled legacy interfaces backed by GLFW and OpenAL; remove the need for an OpenGL rendering context.
- Improve fullscreen changes, resizing, high-resolution mouse coordinates, relative mouse movement, keyboard events, and audio reinitialization.
- Update the Java build dependencies and compile Vulkan shaders during the normal build.
- Expose terrain-build, trigger-query, held-light, collision, and script-scheduler diagnostic counters.
- Replace the Python wiki tools with a standalone Gradle/Groovy build and refresh wiki generation, previews, registry assets, and publication workflows. Add mapper guides for materials and shader creation.
